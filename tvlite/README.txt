TV LITE — лёгкий лаунчер для Xiaomi TV (и других слабых Android TV)
====================================================================

Что это: главный экран без фоновых служб. Тёмный фон с мягкими цветными
пятнами, тонкие часы, ряд «Избранное», ряд «Приложения», выбор HDMI-источника.
Плитки «стеклянные»: полупрозрачные, со светлой рамкой. Анимация только
в момент перехода фокуса (плитка чуть увеличивается). Интернет-доступа
у приложения нет (разрешений в манифесте нет вообще).

О ГЛАССМОРФИЗМЕ: настоящее размытие «на лету» слишком тяжело для GPU
этого ТВ, поэтому размытый фон рисуется один раз при запуске и потом
остаётся статичной картинкой, а плитки полупрозрачные поверх него.
Выглядит как стекло, нагрузки почти нет.

ИКОНКИ: у приложений родные цветные иконки на стеклянных плитках.
Служебные плитки (Источники, Настройки, Скрытые) нарисованы тонкими
линиями. Чужие иконки я перерисовать не могу, но есть режим «минимализм»:
удержание OK на любом приложении -> «Иконки: приглушить (минимализм)».
Тогда в покое иконки почти серые, а цвет возвращается только у выбранной.

ШАГ 1. СОБРАТЬ APK
------------------
Способ А (без установки программ, через сайт GitHub):
 1. Зайдите на github.com и войдите (или зарегистрируйтесь, это бесплатно).
 2. New repository -> имя любое (например tvlite) -> Private -> Create.
 3. В репозитории: Add file -> Upload files -> перетащите ВСЁ содержимое
    этой папки (включая папки app, gradle и .github) -> Commit changes.
    Если папка .github не загрузилась (она скрытая): Add file -> Create new
    file, в поле имени введите  .github/workflows/build.yml  и вставьте
    туда содержимое файла build.yml из этого архива.
 4. Вкладка Actions -> запуск «Build APK» -> дождитесь зелёной галочки
    (около 5-8 минут).
 5. Откройте этот запуск -> внизу раздел Artifacts -> TVLite-apk -> скачать.
    Внутри zip лежит app-release.apk.

Способ Б (если на ПК стоит Android Studio):
 File -> Open -> эта папка -> Build -> Build App Bundle(s)/APK(s) -> Build APK(s).

ШАГ 2. УСТАНОВИТЬ (cmd, в папке platform-tools, ТВ включён)
-----------------------------------------------------------
    .\adb connect 192.168.1.69:5555
    .\adb install -r app-release.apk

ШАГ 3. ПРОБНЫЙ ЗАПУСК (главный экран пока НЕ меняется)
------------------------------------------------------
    .\adb shell am start -n ru.tvlite.launcher/.MainActivity

Проверьте пультом: листание рядов, запуск YouTube/ВК, плитка «Источники»
(выбор HDMI), удержание OK на приложении (меню). Кнопка Home вернёт вас
в Projectivy, пока TV Lite не назначен главным.

ШАГ 4. СДЕЛАТЬ ГЛАВНЫМ (только если пробный запуск понравился)
--------------------------------------------------------------
    .\adb shell cmd package set-home-activity ru.tvlite.launcher/.MainActivity

ОТКАТ (в любой момент)
----------------------
    .\adb uninstall ru.tvlite.launcher
Главным экраном снова станет Projectivy.

УПРАВЛЕНИЕ
----------
 * Удержание OK на приложении (или кнопка Menu): добавить в избранное /
   убрать / скрыть / «О приложении» (там можно удалить) / цветные или
   приглушённые иконки.
 * Скрытые приложения возвращаются: Приложения -> плитка «Скрытые».
 * При первом запуске в «Избранное» попадают, если установлены: SmartTube,
   YouTube, ВК, Rutube, Кинопоиск, ivi, Яндекс Браузер, ByeByeDPI.
   Список лежит в MainActivity.java (массив PREFERRED).

ОГРАНИЧЕНИЯ (честно)
--------------------
 * Код проверен компиляцией против Android API 30 и 34, но на вашем ТВ
   не запускался. Первый запуск на устройстве это и есть проверка.
 * «Источники» используют стандартный TV Input Framework. Работает ли
   переключение HDMI на вашей прошивке Xiaomi, заранее неизвестно.
 * APK подписан отладочным ключом: для установки через adb этого хватает,
   в магазины такое не загружают.
